# Caffè Sospeso — One Page Premium Conversion

Pacchetto statico pronto per GitHub Pages, Vercel o Netlify.

## Obiettivo
Presentare a Caffè Sospeso una proposta molto più forte dell'attuale sito vetrina:
- conversione verso WhatsApp;
- colazioni prenotabili dalle **07:00 alle 10:00**;
- evidenza dell'**ordine minimo €5**;
- sezioni dedicate a **dolci**, **gelateria**, **stuzzicheria**;
- blocco finale posizione/contatti;
- esperienza mobile curata.

## File
- `index.html`
- `assets/css/styles.css`
- `assets/js/app.js`
- `assets/img/*.svg`
- `vercel.json`

## Funzioni inserite
- Header sticky responsive.
- Hero premium con posizionamento forte.
- Sezione colazioni con elenco paste e caffetteria.
- Modulo selezione prodotti + fascia ritiro + nome + note.
- Verifica UX del minimo ordine tramite checkbox dedicata.
- Apertura WhatsApp con riepilogo già compilato.
- Sezione gelato con formati 0,5 kg / 1 kg / 1,5 kg.
- Sezione dolci e torte.
- Sezione stuzzicheria €0,90 al pezzo.
- CTA WhatsApp specializzate per ogni servizio.
- Mappa/posizione con apertura ricerca Google Maps.
- Dati strutturati LocalBusiness / CafeOrCoffeeShop.

## Nota strategica
Non sono stati inseriti prezzi colazione inventati. Il sito conserva il vincolo **ordine minimo €5** e richiede conferma totale direttamente in chat, finché il listino ufficiale non viene fornito.

## Verifiche da fare prima di una pubblicazione reale
- Civico esatto da mostrare in pagina e in mappa.
- Gusti gelato effettivi.
- Eventuali prezzi delle vaschette gelato.
- Modalità operative: solo ritiro, consegna locale o entrambe.
- Eventuali tempi minimi di prenotazione per torte/stuzzicheria.

## Deploy rapido su GitHub Pages
1. Crea un repository GitHub.
2. Carica il contenuto della cartella.
3. Vai in **Settings → Pages**.
4. Pubblica dal branch `main`, cartella `/root`.

## Deploy rapido su Vercel
1. Importa il repository.
2. Framework: **Other**.
3. Root directory: `/`.
4. Deploy.
