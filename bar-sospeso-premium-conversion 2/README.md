# Caffè Sospeso – Shop & Prenotazioni Premium

One-page premium pronta per GitHub Pages o Vercel.

## Aggiornamento principale
Questa versione non è più una semplice landing dimostrativa: è stata trasformata in un vero **shop di prenotazioni** con navigazione più fluida, palette chiara e struttura commerciale avanzata.

## Funzionalità presenti
- Header premium con logo reale Caffè Sospeso.
- Palette chiara crema / panna / rosso brand.
- Shop filtrabile per categorie.
- Ricerca prodotti in tempo reale.
- Aggiunta prodotti al carrello.
- Carrello laterale con quantità, rimozione e riepilogo.
- Invio ordine su WhatsApp con messaggio già compilato.
- Gestione regola colazioni: servizio 07:00–10:00 e conferma minimo €5.
- Schede reali per:
  - cornetti e paste da colazione;
  - torte e dolci;
  - vaschette gelato 0,5 kg / 1 kg / 1,5 kg;
  - stuzzicheria a €0,90 al pezzo.
- Moduli dedicati per:
  - richiesta torta;
  - ordine vaschetta gelato;
  - buffet / stuzzicheria.
- CTA WhatsApp realmente cliccabili.
- Sezione contatti e mappa.
- Responsive mobile più curato.

## File

## Deploy su GitHub / Vercel
1. Carica i file del progetto nel repository.
2. Su Vercel importa il repository.
3. Framework: `Other` / static site.
4. Output automatico: la root del progetto.

## Dati da verificare prima della pubblicazione definitiva
- Prezzi pubblici dei prodotti senza listino mostrato.
- Gusti gelato effettivamente disponibili in quel periodo.
- Eventuali condizioni su tempi di preavviso per torte e buffet.
- Civico definitivo da esporre in modo uniforme su tutto il sito.
